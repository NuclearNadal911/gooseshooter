Description and goal of the game

This web app was created as a school project. It is my interpretation of a classic arcade game "Duck Hunt" in realistic visual style. the player's task is to shoot down geese within a time limit. As the score increases(milestones of 10, 50 and 100 points), the game dynamically becomes more difficult, the time limit per round is shortened and thus the game becomes more challenging.
